Design a premium, responsive **Customer Registration** page for BridgePay.

## About BridgePay

BridgePay is a Hire Purchase Marketplace where customers discover products from verified stores and purchase them through flexible installment payment plans.

This page allows new customers to create a BridgePay account before applying for hire purchase.

The registration experience should be modern, simple, secure, and welcoming. Instead of displaying one long form, design it as a professional **4-step registration wizard** with a progress indicator.

The UI should match the BridgePay Design System and feel similar to Stripe, Apple, Airbnb, Revolut, Klarna, and Shopify.

Use the existing BridgePay Design System.

• Primary Blue (#0B5FFF)
• Dark Navy (#101828)
• Gold Accent (#D4A017)
• Gray Background (#F8FAFC)
• White (#FFFFFF)
• Inter Font
• Auto Layout
• 8px spacing system
• 16px border radius
• Soft shadows
• Responsive Desktop, Tablet and Mobile

FIGMA REQUIREMENTS

• Use Auto Layout throughout.
• Create reusable components and variants.
• Use Variables for colors, spacing, typography, radius, and shadows.
• Follow an 8px spacing system.
• Use proper layer naming.
• Design every form element as a reusable component.
• Include hover, focus, disabled, loading, success, and error states.
• Ensure accessibility with readable typography, keyboard-friendly navigation, and clear validation messages.
• Build a production-ready design suitable for direct frontend development.

The final Customer Registration page should feel welcoming, secure, and effortless, guiding new users through a clean multi-step onboarding experience while building confidence in the BridgePay platform.
