Design a premium, responsive marketplace page for BridgePay called **Browse Stores**.

## About BridgePay

BridgePay is a Hire Purchase Marketplace where customers browse verified stores, explore products, and purchase them through flexible installment payments.

This page is the marketplace directory where users discover all available stores before choosing a product.

The UI should feel premium, modern, trustworthy, and highly polished, similar to Airbnb, Apple, Stripe, Shopify, and Klarna.

Use the existing BridgePay Design System:
• Primary Blue (#0B5FFF)
• Dark Navy (#101828)
• Gold Accent (#D4A017)
• Gray Background (#F8FAFC)
• White (#FFFFFF)
• Inter Typography
• 8px spacing system
• 16px border radius
• Soft shadows
• Auto Layout
• Component-based design
• Desktop, Tablet and Mobile responsive

• Create reusable components and variants.
• Use Variables for colors, typography, spacing, and shadows.
• Maintain pixel-perfect spacing with an 8px grid.
• Properly name all layers and frames.
• Build a developer-ready design system.
• Ensure accessibility with clear contrast, large touch targets, and readable typography.

The final design should feel like a premium online marketplace where customers can confidently discover, compare, and choose trusted stores before browsing products.
