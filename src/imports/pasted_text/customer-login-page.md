Design a premium, responsive **Customer Login** page for BridgePay.

## About BridgePay

BridgePay is a modern Hire Purchase Marketplace where customers browse verified stores, purchase products through flexible installment plans, and manage repayments securely.

This page allows existing customers to securely access their BridgePay account.

The login experience should be clean, trustworthy, modern, and frictionless, inspired by Stripe, Apple, Klarna, PayPal, and Revolut.

Use the existing BridgePay Design System.

• Primary Blue (#0B5FFF)
• Dark Navy (#101828)
• Gold Accent (#D4A017)
• Gray Background (#F8FAFC)
• White (#FFFFFF)
• Inter Font
• Auto Layout
• 8px spacing system
• 16px border radius
• Soft shadows
• Responsive Desktop, Tablet, and Mobile

FIGMA REQUIREMENTS

• Use Auto Layout throughout.

• Create reusable components and variants.

• Use Variables for colors, typography, spacing, shadows, and border radius.

• Follow an 8px spacing system.

• Name all layers and frames properly.

• Design hover, focus, disabled, loading, success, and error states.

• Ensure accessibility with keyboard navigation, readable typography, and sufficient color contrast.

• Build a production-ready interface suitable for direct frontend implementation.

The final Login page should immediately build trust, provide a frictionless sign-in experience, and guide customers securely into their BridgePay dashboard while maintaining a premium fintech appearance.
