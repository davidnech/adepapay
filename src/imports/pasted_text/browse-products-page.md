Design a premium, responsive **Browse Products** page for BridgePay.

## About BridgePay

BridgePay is a modern Hire Purchase Marketplace where customers browse products from verified stores and purchase them through flexible installment payment plans.

This page is the main product marketplace where customers discover, compare, filter, and search products before viewing detailed information or applying for hire purchase.

The interface should feel like a premium e-commerce marketplace inspired by Amazon, Apple, Shopify, Klarna, and Stripe, while maintaining the BridgePay design language.

Use the existing BridgePay Design System.

• Primary Blue (#0B5FFF)
• Dark Navy (#101828)
• Gold Accent (#D4A017)
• Gray Background (#F8FAFC)
• White (#FFFFFF)
• Inter Font
• Auto Layout
• 8px spacing system
• 16px border radius
• Soft shadows
• Fully responsive (Desktop, Tablet & Mobile)

• Use Auto Layout throughout.
• Create reusable components and variants.
• Use Variables for colors, typography, spacing, shadows, and radius.
• Follow an 8px spacing system.
• Name all layers and frames clearly.
• Build reusable cards, filters, buttons, badges, and layouts.
• Ensure accessibility with strong contrast, readable typography, and large touch targets.
• Produce a pixel-perfect, developer-ready design suitable for production.

The final Browse Products page should feel like a premium online marketplace where customers can confidently search, filter, compare, and discover products from verified stores before viewing detailed product information or starting a hire purchase application.
