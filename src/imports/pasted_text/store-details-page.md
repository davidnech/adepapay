Design a premium, responsive **Store Details** page for BridgePay.

## About BridgePay

BridgePay is a Hire Purchase Marketplace where customers browse verified stores, discover products, and purchase products through flexible installment payments.

This page represents a single merchant's storefront. It should help customers evaluate the store, build trust, browse products, and start a hire purchase application.

The interface should look like a world-class marketplace combining the quality of Shopify, Apple, Airbnb, Amazon Storefront, Stripe, and Klarna.

Use the existing BridgePay Design System.

• Primary Blue (#0B5FFF)
• Dark Navy (#101828)
• Gold Accent (#D4A017)
• Gray Background (#F8FAFC)
• White (#FFFFFF)
• Inter Font
• Auto Layout
• 8px spacing
• 16px border radius
• Soft shadows
• Responsive Desktop, Tablet and Mobile
